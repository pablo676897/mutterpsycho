# MutterPsycho

Duolingo-stílusú tanuló app a klinikai és egészségpszichológia MSc záróvizsgához. A 25 záróvizsga-tétel sorrendjében halad, plusz bónusz egységek a tantárgyi anyagokból. XP, napi sorozat, szívek, hibajavítás, vegyes ismétlés. PWA – telepíthető és offline is működik.

## GitHub Pages bekapcsolása

**Settings → Pages → Source: Deploy from a branch**, branch `main`, folder `/ (root)`, Save.
Pár perc múlva elérhető: `https://pablo676897.github.io/mutterpsycho/`

## Telepítés telefonra

- **Android (Chrome):** link megnyitása → ⋮ menü → *Alkalmazás telepítése*
- **iPhone (Safari):** link megnyitása → Megosztás → *Főképernyőhöz adás*

## Megjegyzések

- A haladás a böngészőben mentődik (localStorage), eszközönként külön.
- A leckék a `content.js` fájlban vannak; frissítéskor automatikusan betöltődnek.
